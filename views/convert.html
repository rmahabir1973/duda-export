Convert to PDF

Drop Word, Excel, PowerPoint or OpenDocument files here and get PDFs back. One file returns a PDF; several return a ZIP, or tick Merge for one combined PDF in the order listed. Files are converted in memory and not kept.

    For developers: the same conversion from a church site

    POST /api/v1/convert/pdf as multipart/form-data with one or more file fields and the site's gateway token in Authorization: Bearer …. Add merge=1 for one combined PDF. The response is a PDF (or a ZIP of PDFs). 120 conversions an hour per site, 25 MB per file.
